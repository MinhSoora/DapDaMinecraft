# -p-Minecraft
Minecraft Stone Clicker là một mini game HTML lấy cảm hứng từ Minecraft. Người chơi chỉ cần click vào cục đá để kiếm điểm, mở khóa các thành tựu theo phong cách Minecraft, tăng level thông qua thanh XP và nghe nhạc nền Minecraft thư giãn. Toàn bộ tiến trình được lưu tự động trên trình duyệt bằng LocalStorage.
